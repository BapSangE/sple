# Sple 2차 심화 고도화 작업 명세서 (Advanced Phase)

## Phase 1: 추가 오류(Error) 및 예외 처리 테스트 (우선순위: 1)
> 서비스 확장 시 발생할 수 있는 데이터 정합성 및 기기 호환성 관련 테스트입니다.

1. **좌표-주소 변환(Reverse Geocoding) 실패:** AI가 인스타 장소명은 찾았으나 지도 API 상에서 좌표값이 반환되지 않을 때, 무한 로딩 방지 및 '수동 장소 지정' 유도 확인.
2. **클립보드 접근 권한 오류:** 링크 붙여넣기 시 사용자가 클립보드 접근을 거부한 경우, 서비스가 멈추지 않고 직접 입력창으로 자연스럽게 안내되는지 확인.
3. **PWA 오프라인 대응:** 네트워크 연결이 끊긴 상태에서 진입 시, 흰 화면 대신 '네트워크 연결 확인' 안내 문구와 오프라인 아이콘이 정상 출력되는지 테스트.
4. **중복 저장 로직 검증:** 동일한 인스타그램 URL을 여러 번 입력했을 때, 새로운 마커를 생성하지 않고 기존 마커를 강조(Highlight)해주며 알림을 띄우는지 확인.
5. **iOS/Android 시스템 제스처 간섭:** 모바일 웹 환경에서 하단 스와이프 제스처 시 바텀 시트와 브라우저 내비게이션 바가 겹쳐 클릭이 안 되는 현상 체크.

## Phase 2: 심화 사용자 편의성(UX) 고도화 (우선순위: 2)
> 유저의 재방문율을 높이고 실제 방문으로 이어지게 하는 11가지 기능입니다.

1. **외부 내비게이션 연동:** 상세 페이지에서 '카카오내비', 'Tmap', '네이버 지도' 앱으로 즉시 길안내를 시작할 수 있는 버튼 구현.
2. **외부 리뷰 서비스 연결:** 해당 장소의 '네이버 플레이스' 또는 '카카오맵 리뷰' 페이지로 바로 연결되는 아웃링크 제공.
3. **목록 뷰(List View) 토글:** 지도 화면 상단의 마커들을 한눈에 볼 수 있도록 '리스트로 보기' 전환 버튼 추가.
4. **나만의 장소 폴더링:** 저장한 핫플을 '가고 싶은 곳', '이미 가본 곳', '데이트 코스' 등으로 분류할 수 있는 폴더 기능.
5. **개인 메모 기능:** AI 정보 외에 사용자가 직접 "웨이팅 있음", "커피 맛있음" 등 짧은 메모를 남길 수 있는 필드 추가.
6. **현재 위치 기반 '이 지역 재검색':** 지도를 이동했을 때 해당 영역 내에 저장된 핫플들만 다시 필터링하여 보여주는 기능.
7. **필터 다중 선택(Multi-select):** '카페'와 '식당' 카테고리를 동시에 선택해서 볼 수 있도록 필터 로직 개선.
8. **장소 공유하기:** 특정 장소 정보나 내가 만든 지도를 친구에게 카카오톡/링크로 공유할 수 있는 공유 버튼 추가.
9. **검색 히스토리:** 최근 검색한 지역이나 장소명을 검색창 하단에 칩(Chip) 형태로 노출하여 재입력 불편 해소.
10. **사진 썸네일 노출:** 마커 클릭 시 하단 바텀 시트에 해당 인스타그램 게시물의 대표 이미지나 장소 사진을 작게 미리보기로 제공.
11. **PWA 설치 유도:** 모바일 브라우저 하단에 '앱으로 추가' 배너를 노출하여 바탕화면에 바로가기를 생성하도록 유도.

## Phase 3: 심화 디자인(UI) 고도화 (우선순위: 3)
> 브랜드 아이덴티티를 확립하고 인터랙션의 완성도를 높이는 11가지 개선안입니다.

1. **마커 애니메이션:** 특정 장소를 클릭하거나 목록에서 선택했을 때, 지도 위 해당 마커가 통통 튀는(Bounce) 효과 추가.
2. **유리창 효과(Glassmorphism):** 하단 바텀 시트와 상단 필터 바 배경에 반투명 블러 처리를 주어 지도가 은은하게 비치도록 세련미 강화.
3. **로딩 브랜딩:** 기본 스피너 대신 Sple 로고나 픽토그램을 활용한 전용 로딩 애니메이션 적용.
4. **빈 화면(Empty State) 디자인:** 검색 결과가 없거나 저장한 장소가 없을 때, 사용자를 가이드하는 캐릭터 일러스트와 문구 배치.
5. **토스트 메시지 시스템:** '저장되었습니다', '복사되었습니다' 등 상태 피드백을 화면 하단에 플로팅 형태로 세련되게 노출.
6. **탭 피드백(Haptic/Visual):** 버튼 클릭 시 크기가 살짝 줄어들거나 색상이 변하는 즉각적인 반응(Micro-interaction) 강화.
7. **커스텀 지도 스타일링:** 카카오맵 기본 테마 대신 서비스 브랜드 컬러와 어울리는 Soft Gray 또는 톤다운된 커스텀 지도 시트 적용.
8. **일관된 아이콘 시스템:** 카테고리별 아이콘을 동일한 선 굵기(Line Weight)와 스타일을 가진 커스텀 아이콘 셋으로 교체.
9. **상태바(Status Bar) 대응:** 모바일 전체 화면 모드 시 기기 상단 상태바 영역과 콘텐츠가 겹치지 않도록 Safe Area 여백 최적화.
10. **스켈레톤 UI 심화:** 지도 타일이나 데이터 로드 시, 실제 레이아웃 구조와 동일한 형태의 스켈레톤 애니메이션 적용.
11. **가독성 높은 폰트 계층:** Pretendard 등 가독성이 검증된 폰트를 적용하고, 제목과 본문의 명도 대비를 높여 시인성 개선.
