# Sple 디자인 및 기술 의사결정 저널 (Design & Tech Journal)

스플(Sple) 프로젝트의 UI 고도화 및 브랜딩 강화 과정에서 발생한 핵심 문제와 해결 과정을 기록한 문서입니다.

## 1. 내비게이션 아이콘 시각적 노이즈 문제

### **[문제(Problem)]**
- 하단 내비게이션 아이콘 주변에 불투명한 사각형 박스가 노출되어 지도의 미관을 해침.
- 아이콘 선명도가 낮아 프리미엄 디자인 느낌이 부족함.

### **[시도(Trial)]**
1. **이미지 최적화**: 생성된 PNG 이미지의 배경을 투명하게 처리하고 CSS `object-contain`을 적용했으나, 브라우저 렌더링 방식 및 이미지 품질 한계로 인해 박스 잔상이 여전히 발생함.
2. **SVG 전환**: 이미지를 고해상도 인라인 SVG 코드로 전면 교체함.

### **[해결(Solution)]**
- **인라인 SVG 적용**: 코드 기반 렌더링으로 배경 노이즈를 100% 제거하고, 브랜드 컬러(#FF5A5F)를 코드에서 직접 제어하여 선명도를 극대화함.

## 2. 브랜딩 및 로고 정체성 강화

### **[문제(Problem)]**
- 초기 생성된 로고에 텍스트가 포함되어 미니멀한 모바일 디자인에 부적합함.
- 파비콘과 앱 아이콘이 통일되지 않아 브랜드 인지도가 낮음.

### **[시도(Trial)]**
- 인공지능 이미지 생성을 통해 '텍스트를 배제한 심볼형 로고' 제작. 지도 핀과 스크랩 클립을 결합한 독창적 형태 도출.

### **[해결(Solution)]**
- **글로벌 아이콘 일원화**: 재생성된 심볼을 `app-icon-512`, `icon-192`, `favicon.ico`에 일괄 적용하여 브랜드 아이덴티티를 통일함.

## 3. 디자인 변경 후 기능 중단 이슈 (진행 중)

### **[문제(Problem)]**
- HTML 구조 변경 및 JS 로직 추가 과정에서 Kakao Maps API 로드 실패 시 전체 스크립트가 멈추는 현상 발생.
- 내비게이션 탭 전환이 시각적으로만 보이고 실제 화면(섹션)이 바뀌지 않음.

### **[시도(Trial)]**
- `switchTab` 함수 정의 및 인라인 `onclick` 이벤트 적용.

### **[해결 방안(Upcoming solution)]**
- **에러 격리 (Error Isolation)**: 지도 API 에러가 UI 인터랙션에 영향을 주지 않도록 Try-Catch 구문 도입 및 초기화 로직 분리.
- **섹션 전환 로직 완성**: 각 탭에 대응하는 HTML `<section>`의 가시성 제어 로직 보강.
