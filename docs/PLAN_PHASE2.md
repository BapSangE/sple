# Sple Phase 2 고도화 계획

본 문서는 Sple의 2차 심화 고도화 작업 명세서를 바탕으로 작성된 실행 계획서입니다. 에이전트는 본 계획에 따라 오류 검증, UX 개선, 디자인 시스템 주입 등의 작업을 순차적으로 진행합니다.

## Phase 1: 예외 처리 및 방어 로직 구현
1. **좌표 변환 실패 처리:** 카카오맵 검색 실패 시 팝업 및 수동 입력 UI 제공
2. **클립보드 권한 예외 처리:** 클립보드 권한 거부 시 수동 입력 유도 
3. **PWA 오프라인 모드:** 오프라인 시 안내 페이지 노출 및 상태 감지 아이콘 표시
4. **중복 마커 방지:** 중복 URL/장소 저장 시 기존 마커 강조 애니메이션 및 토스트 알림
5. **제스처 충돌 해결:** 바텀 시트와 지도의 터치 이벤트 버블링 분리 및 충돌 제어

## Phase 2: 심화 사용자 편의성(UX) 고도화
1. **외부 앱 연동:** 카카오내비, 네이버지도, Tmap 등 외부 길찾기 앱 딥링크 연결 (앱 미설치 시 웹/스토어 fallback 처리)
2. **리스트 뷰 토글:** 지도 화면과 리스트 뷰 간의 원활한 전환(View Toggle) 제공
3. **장소 폴더링 & 다중 필터:** DB 스키마 업데이트를 통한 폴더 관리 및 필터 다중 선택 기능 구현
4. **개인 메모 및 썸네일:** 장소 저장 시 메모 작성 기능(DB 연동) 및 클릭 시 사진 썸네일 표시
5. **검색 히스토리:** localStorage 기반 최근 검색어 칩(Chip) 제공
6. **앱 설치 유도 및 공유:** PWA 설치 유도 배너 구현 및 카카오톡/링크 공유 기능 추가

## Phase 3: 심화 디자인(UI) 고도화 (Stitch MCP 연동)
1. **Stitch 디자인 시스템 주입:** 스플 브랜드 색상(코랄, 스마트 퍼플, 가이드 민트) 및 Typography 전면 적용
2. **유리창 효과(Glassmorphism):** 바텀 시트 및 상단 UI 컴포넌트에 블러 및 반투명 배경 적용
3. **로딩 및 스켈레톤 UI:** 컴포넌트별 스켈레톤 애니메이션 및 브랜드 스피너 적용
4. **Empty State 및 토스트:** 데이터 없음 가이드 일러스트레이션 및 상태 알림 토스트 시스템 구축
5. **모바일 최적화:** Safe Area 완벽 대응 및 액션 시 미세한 Haptic/Visual 피드백 추가
6. **커스텀 마커 & 아이콘:** 카카오맵 기본 마커를 커스텀 브랜드 마커로 교체하고, 아이콘 패밀리 통일
