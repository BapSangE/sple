# Sple 서비스 고도화 작업 명세서 (Agent 실행용)

## Phase 1: 오류(Error) 검증 및 예외 처리 테스트 (우선순위: 1)
> 기능 구현 시 발생할 수 있는 잠재적 오류에 대한 테스트 케이스입니다.

1. **인스타그램 URL 파싱 예외 처리:** 비공개 계정, 삭제된 게시물, 위치 태그가 없는 게시물 링크 입력 시 앱 크래시 방지 및 안내 메시지 출력 확인.
2. **권한 거부 처리:** 사용자가 위치 정보(GPS) 권한을 거부했을 때, 지도 무한 로딩이나 튕김 현상 없이 기본 좌표(예: 서울 중심)로 렌더링되는지 테스트.
3. **API 한도 초과 대응:** 카카오맵 API 또는 인스타그램 파싱 AI 서버의 일일 호출 한도 초과 시 발생하는 500 에러 처리 및 사용자용 Fallback UI(안내 모달) 작동 여부.
4. **마커 렌더링 과부하:** 지역 필터 '전체' 선택 후 넓은 반경에서 100개 이상의 핫플 마커를 렌더링할 때 브라우저 메모리 누수 및 프레임 드랍 발생 여부 체크.
5. **세션 만료 리다이렉트:** 로그인 상태에서 장시간 방치 후 토큰이 만료되었을 때, 핫플 저장 등의 액션을 취하면 정상적으로 401 에러를 잡고 로그인 페이지로 유도하는지 확인.

## Phase 2: 사용자 편의성(UX) 고도화 (우선순위: 2)
> 사용자 경험 향상을 위한 11가지 기능 및 플로우 개선 작업입니다.

1. **링크 입력창 직관성 개선:** 웹 환경에서 '게시물의 [공유하기] 버튼을 눌러 스플로 보내면'이라는 안내는 작동 방식이 모호함. 직관적인 '인스타그램 링크 붙여넣기' 입력 필드 및 버튼 추가.
2. **내 위치 복귀(GPS) 버튼:** 지도 화면 우측 하단에 현재 사용자의 위치로 지도를 이동시키는 타겟팅 버튼 추가.
3. **바텀 시트 컨트롤 도입:** 하단의 안내 시트가 지도 영역을 가리고 있으므로, 스와이프 다운(또는 최소화 버튼)하여 시트를 내리고 지도를 넓게 볼 수 있는 기능 추가.
4. **상태 피드백(Loading) 제공:** AI가 인스타 게시물에서 장소 정보를 추출하는 동안 사용자가 이탈하지 않도록 명확한 로딩 인디케이터(Lottie 애니메이션 또는 프로그레스 바) 적용.
5. **검색 기능 고도화:** '어디로 갈까요?' 검색창 터치 시, 단순 텍스트 입력만 받는 것이 아니라 '최근 검색 지역' 및 '인기 검색어' 자동완성 패널 제공.
6. **필터 가로 스크롤 힌트:** 상단 카테고리(카페, 식당, 술집 등) 영역 우측 끝에 그라데이션 페이드아웃 효과를 주어 뒤에 더 많은 필터가 숨겨져 있음을 암시.
7. **에디터 픽 액션 사전 안내:** '성수동 에디터 픽 미리보기' 버튼 클릭 시, 지도가 이동하는지 혹은 리스트가 뜨는지 알 수 있도록 우측에 화살표(`>`)나 리스트 아이콘 추가.
8. **로그인 후 상태 명확화:** 로그인 완료 후 '로그인' 텍스트를 사용자 프로필 썸네일이나 '마이페이지' 아이콘으로 변경하여 로그인 상태임을 명확히 인지시킴.
9. **지도 줌 컨트롤 추가:** 모바일 브라우저 환경에서 핀치 줌에 익숙하지 않은 사용자를 위해 화면 우측에 직관적인 `+`, `-` 줌 컨트롤 버튼 배치.
10. **온보딩 툴팁 제공:** 신규 유저가 접속했을 때, 인스타그램 화면에서 스플로 공유하는 과정을 3초짜리 짧은 GIF 툴팁으로 보여주어 학습 비용 단축.
11. **마커 클러스터링 적용:** 축소가 많이 된 지도에서 핀이 겹쳐서 클릭이 불가능한 현상을 방지하기 위해, 숫자로 묶여서 보이는 마커 클러스터링(Clustering) 기능 도입.

## Phase 3: 디자인(UI) 고도화 (우선순위: 3)
> 시각적 완성도와 인터페이스 규격을 맞추기 위한 11가지 개선 작업입니다.

1. **브랜드 컬러 시스템 통일:** 좌측 상단 로고(Sple)의 코랄 레드 톤과 하단 에디터 픽 버튼의 퍼플 톤이 분산되어 있음. Primary Color를 1가지로 통일하여 적용.
2. **카테고리 활성화(Active) 상태 디자인:** 현재 상단 필터 아이콘들이 모두 비활성화된 회색 톤으로 보임. 선택된 카테고리는 Primary Color로 변경되고 폰트 웨이트(Bold)가 변하는 시각적 피드백 적용.
3. **바텀 시트 Elevation(그림자) 강화:** 바텀 시트와 뒷배경 지도 간의 깊이감 구분을 위해 바텀 시트 상단 가장자리에 부드러운 드롭 섀도우(Drop Shadow) 추가.
4. **검색창 명도 대비(Contrast) 개선:** 검색창의 배경색과 '어디로 갈까요?' placeholder 텍스트의 명도 대비를 높여 접근성(WCAG 기준) 및 시인성 향상.
5. **터치 타겟(Touch Target) 사이즈 확보:** 모바일 웹 접근성을 위해 카테고리 아이콘, 로그인 텍스트 등 모든 클릭 요소의 최소 터치 영역을 44x44px 이상으로 패딩 조정.
6. **타이포그래피 계층(Hierarchy) 정리:** 바텀 시트 내 '가장 쉽게 저장하세요' (Title)와 그 아래 설명글 (Description) 간의 폰트 크기 및 색상(Solid Black vs Gray) 대비를 더 확실하게 주어 정보의 위계를 명확히 함.
7. **커스텀 맵 마커 디자인:** 카카오맵의 기본 핀 형태를 제거하고, Sple의 브랜드 로고나 카테고리를 나타내는 픽토그램이 들어간 커스텀 마커 이미지로 교체.
8. **아이콘 메타포 수정:** 바텀 시트 중앙의 카메라 아이콘이 '사진 촬영'으로 오인될 수 있음. 링크 연동이나 AI 탐색을 상징하는 아이콘(예: 링크, 반짝이는 로봇 아이콘 등)으로 교체.
9. **헤더 레이아웃 여백 교정:** 검색창 컴포넌트와 우측 '로그인' 텍스트 사이의 여백이 좁고 정렬이 불안정함. 여백(Margin)을 재조정하고 수직 중앙 정렬(Align-items: center) 보정.
10. **스켈레톤(Skeleton) UI 적용:** 네트워크가 느린 환경에서 지도 타일이나 하단 배너 이미지가 로드되기 전, 빈 화면이나 엑스박스 대신 형태를 유지하는 스켈레톤 애니메이션 적용.
11. **시스템 다크모드 대응 지원:** 사용자의 OS 테마 설정에 맞춰 지도 테마(카카오맵 다크 테마) 및 UI 컴포넌트(배경, 폰트 컬러 역전)가 자연스럽게 전환되도록 CSS 변수(Variable) 세팅.
