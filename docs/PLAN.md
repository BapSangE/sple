# 스플(Sple) MVP 자율형 개발 워크플로우 (Harness & Agent 파이프라인)

본 문서는 `agent.md`, `harness.md` 및 `스플(Sple) - MVP 서비스 기획 문서.md`를 통합하여 작성된 자율형 에이전트의 실행 계획서입니다.

## 📌 Step 1: 기획 분석 및 초기화 (Plan)
1. **하네스 환경 구성:** `docs/`, `src/`, `tests/`, `logs/` 구조를 확립하고 문서 간 교차 링크를 구성합니다.
2. **디자인 DNA 주입 (Stitch MCP):** 
   - Stitch MCP 서버와 연동하여 스플의 핵심 색상(Primary: 스플 코랄 `#FF5A5F`, Secondary: 스마트 퍼플 `#6B4EFF`, Accent: 가이드 민트 `#00D09E`)과 폰트 등 글로벌 테마를 로드합니다.
   - 디자인 하드코딩을 원천 차단하고 시스템 에셋을 기반으로 컴포넌트를 구성합니다.

## 📌 Step 2: UI 뼈대 구축 (Execute - Frontend)
1. **지도 중심 설계:** 
   - **카카오 지도 API**를 우선 연동하여 앱 메인 화면의 80% 이상을 지도로 렌더링합니다.
2. **바텀 시트 (Bottom Sheet):** 
   - 화면 하단 20%에 스와이프 업(Swipe-up) 인터랙션이 가능한 바텀 시트 컴포넌트를 배치하여 요약/상세 정보를 제공합니다.
3. **콜드 스타트 가이드 (Cold Start):** 
   - 진입 시 전체 화면 팝업을 배제합니다.
   - 우측 하단의 플로팅 버튼(+) 위에 가이드 민트 색상의 '움직이는 툴팁 애니메이션'을 띄워 사용자 액션을 자연스럽게 유도합니다.

## 📌 Step 3: 핵심 로직 연동 (Execute - Backend & MVP Logic)
1. **Share Intent 기반 데이터 수집:** 
   - 모바일 OS의 기본 공유 기능(Share Extension/Intent)을 통해 인스타그램 URL을 전달받는 로직을 구현합니다. *(개인 계정 RPA 크롤링 절대 금지)*
2. **AI 데이터 추출 파이프라인:** 
   - 전달받은 비정형 텍스트를 LLM으로 분석하여 **상호명**과 **행정구역 주소**를 정확하게 추출합니다.
3. **지오코딩 및 마커 매핑:** 
   - 추출된 주소를 지오코딩하여 위경도로 변환하고, 지도 위에 즉각적으로 핀을 꽂아 시각화합니다.
4. **로딩 최적화:** 
   - 앱 전환부터 핀 표시까지의 딜레이를 최소화하여 즉각적인 만족감(Aha-Moment)을 달성합니다.
5. **기록:** 
   - 모든 코드 변경과 추가 사항은 `docs/CHANGELOG.md`에 지속 기록합니다.

## 📌 Step 4: 자율 검증 및 통합 테스트 (Verify)
1. **E2E 플로우 자율 테스트:**
   - [가이드 툴팁 확인] 👉 [인스타그램 공유 연동] 👉 [앱 복귀 후 LLM 파싱 및 핀 생성] 👉 [바텀 시트 상세 확인]에 이르는 핵심 플로우를 테스트합니다.
2. **관측성(Observability) 기반 자체 평가:** 
   - 테스트 실행 후 `logs/` 및 `tests/` 경로에 생성된 데이터를 에이전트가 직접 쿼리하여 결과의 정합성을 검토합니다.
3. **Self-Correction 루프:** 
   - 검토 결과가 기대치에 미치지 못할 경우, 자율적으로 코드를 수정하고 검증 루프를 재수행합니다. 완벽하게 CI/CD를 통과한 시점에만 구현을 완료합니다.
