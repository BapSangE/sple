# 사용자 격리와 분석·저장 안정성

## 변경 동작

- 좌표 복구 프록시는 NextAuth 세션의 사용자 ID를 본문에 주입한다. 백엔드는 해당 사용자의 장소만 조회·수정·반환한다. 전체 사용자 복구 경로는 제공하지 않는다.
- 내부 키가 없으면 기본적으로 시작을 거부한다. 로컬 개발에서만 `APP_ENV=development`와 `ALLOW_INSECURE_LOCAL_AUTH=true`를 모두 명시하면 키 없이 실행할 수 있다. 운영에서는 이 예외를 사용하지 않는다.
- AI 요청은 최대 10,000자, 결과는 최대 50개다. 비동기 Gemini 호출과 스키마 검증을 사용한다. 정상적인 빈 결과는 `[]`, 설정 누락은 503, 형식 오류·외부 장애는 502, 시간 초과는 504, 요청량 제한은 429다.
- AI는 워커당 분당 30회·동시 2회·25초 제한이다. 프로세스 재시작 시 제한 상태가 초기화된다. 여러 워커/인스턴스를 운영할 때는 공유 저장소 기반 제한과 인프라의 요청량 제한을 추가해야 한다. 사용자별 일일 과금 한도를 구현한 것은 아니다.
- 새 프론트엔드는 후보별 UUID `request_id`를 보내며 재시도 시 유지한다. `(user_id, request_id)` 유일 인덱스로 동시 요청과 응답 유실 후 재시도에서도 기존 저장 결과를 반환한다. 기존 클라이언트의 키 없는 요청은 호환된다. 서로 다른 분석에서 새 키로 다시 저장하는 의미상 중복까지 병합하지는 않는다.
- 일부 저장만 실패하면 성공 항목에 저장 완료를 표시하고 실패 항목만 다시 선택한다. 네이버 지오코더가 콜백을 반환하지 않아도 5초 후 좌표 없이 저장을 계속한다.
- 분석 초안은 같은 탭의 sessionStorage에 최대 24시간 유지한다. 선택 상태와 요청 ID도 복원한다. 비로그인 사용자의 저장 버튼은 Google 로그인 후 `/add`로 복귀한다. 사용자 소유 초안은 다른 계정으로 복원하지 않는다. 탭을 닫거나 저장소가 지워지면 초안은 사라진다.
- 네이버 장소 매칭은 이름과 주소 토큰을 함께 확인한다. 동명 매장이나 모호한 지점은 낮은 신뢰도로 남긴다. 주소·이름 수정 시 메타데이터를 초기화한다. matched 캐시는 7일, low_confidence/not_found 캐시는 1시간 후 갱신한다.

## 배포 순서

1. 운영 DB에 `migrations/20260915052753_places_save_request.sql`을 먼저 적용한다. nullable 컬럼과 유일 인덱스를 추가하며 기존 행은 삭제하거나 병합하지 않는다.
2. Vercel과 백엔드의 `BACKEND_API_KEY`가 동일하고 비어 있지 않은지 확인한다.
3. 백엔드를 배포하고 `/health`, `/health/db`를 확인한다.
4. 프론트엔드를 배포한 뒤 본인 계정으로 분석 → 로그인 → 저장 → 리스트·지도 표시를 확인한다.

마이그레이션은 기존 앱과 호환되므로 애플리케이션 롤백 시 컬럼/인덱스를 그대로 둘 수 있다. 이 작업에서는 운영 DB 변경이나 서비스 배포를 실행하지 않았다.

## 검증

- `pytest -q`: 격리된 임시 SQLite에서 권한, 동시 저장, AI 오류/시간 제한, 네이버 매칭과 캐시 회귀 테스트.
- `cd frontend && node --test tests/*.test.mts`: 정규화, 지도/좌표 유틸, 초안과 부분 저장, 캐시 테스트.
- `npm run lint`, `npm run build`.
- `npx playwright install chromium` 후 `npx playwright test`: 로컬 Next.js와 HTTP 백엔드 계약 fixture를 사용한다. Google OAuth 응답만 모의 처리하고 실제 NextAuth 세션 검증을 통과한다. 로그인 복귀, 부분 저장/새로고침/재시도, 타 계정 초안 차단, 복구 프록시 권한, AI 오류 표시를 검증한다.
- 마이그레이션 SQL은 별도 PGlite(PostgreSQL 엔진)에서 반복 적용, 기존 데이터 유지, 중복 거부, 사용자별 키 구분을 확인했다. 운영 Supabase 환경 적용은 별도 절차다.

브라우저 테스트는 실제 Google 계정 로그인, Gemini 추출 품질, 네이버 지도 SDK 인증을 검증하지 않는다. 외부 서비스 자격증명이 필요한 운영 smoke test는 배포 후 수행한다.
