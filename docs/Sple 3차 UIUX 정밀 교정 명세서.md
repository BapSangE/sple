# Sple 3차 UI/UX 정밀 교정 명세서 (디테일 픽스)

## Phase 1: 시인성 및 가독성 정상화 (우선순위: 최상)
> 글자가 보이지 않는 문제를 해결하여 정보 전달의 기본을 갖춥니다.

1. **바텀 시트 텍스트 명도 대비 수정 (치명적):**
   - **문제:** "인스타 핫플을 가장 쉽게 저장하세요" 및 하위 설명 텍스트가 흰색 배경에 매우 연한 회색으로 적용되어 시력이 좋은 사용자도 읽기 힘든 수준임.
   - **해결:** 타이틀 텍스트 컬러를 Dark Gray(#333333) 또는 Black(#111111)으로 변경. 하위 설명은 Medium Gray(#666666) 수준으로 올려 대비를 확실히 줄 것.
2. **상단 카테고리 필터 시인성 개선:**
   - **문제:** [전체], [카페], [식당] 등 칩(Chip) 컴포넌트의 텍스트와 테두리가 너무 연함.
   - **해결:** 기본 상태의 텍스트와 테두리 색상을 조금 더 진하게 조정하고, 선택된 활성 상태(Active)와 미선택 상태의 색상 대비를 명확하게 구분할 것.
3. **검색창 텍스트 가독성:**
   - **문제:** "어디로 갈까요?" Placeholder 텍스트가 얇고 연함.
   - **해결:** 폰트 웨이트(Font-weight)를 한 단계 올리거나 색상을 더 짙게 조정.

## Phase 2: 레이아웃 겹침 및 위치 교정 (우선순위: 상)
> 버튼이 가려지거나 툴팁이 엉뚱한 곳을 가리키는 UI 버그를 수정합니다.

1. **퍼플 배너(툴팁) 잘림 현상 수정 (치명적):**
   - **문제:** "지금 바로 링크를 공유해보세요!" 퍼플 배너가 바텀 시트 영역 뒤로 들어가면서 텍스트 하단이 잘려 보임.
   - **해결:** 해당 배너의 `z-index`를 바텀 시트보다 높게 설정하여 항상 최상단에 노출되도록 수정하거나, 바텀 시트와 겹치지 않게 Y축 위치를 상단으로 끌어올림.
2. **버튼(FAB)과 툴팁의 시각적 연결성 재정립:**
   - **문제:** 퍼플 배너의 말풍선 꼬리가 엉뚱한 곳을 향하거나, 타겟이 되는 우측의 핑크색 링크 버튼(FAB)과의 위치 매칭이 어색함.
   - **해결:** 툴팁 배너를 링크 버튼의 바로 좌측이나 상단으로 이동시키고, 말풍선 꼬리가 정확히 핑크색 버튼을 가리키도록 위치 및 방향 교정.
3. **지도 컨트롤(줌, 내 위치) 정렬:**
   - **문제:** 우측의 지도 컨트롤 버튼들과 하단의 핑크색 링크 버튼 간의 우측 여백(Right Margin) 기준선이 미세하게 틀어져 있어 정돈되지 않은 느낌을 줌.
   - **해결:** 화면 우측 끝에서부터의 여백(예: 16px 또는 20px)을 모든 우측 플로팅 버튼에 동일하게 적용하여 수직 라인을 정렬.
4. **상단 헤더(로고 및 검색창) 여백 확보:**
   - **문제:** Sple 로고, 돋보기 아이콘, 텍스트가 너무 다닥다닥 붙어있어 답답함.
   - **해결:** 컴포넌트 사이의 간격(Gap)을 최소 4~8px 추가하여 숨통을 트여줄 것.

## Phase 3: 크기(Size) 및 비율 최적화 (우선순위: 중)
> 너무 크거나 작은 요소들의 밸런스를 맞춰 사용성을 높입니다.

1. **바텀 시트 높이 및 내부 여백(Padding) 축소:**
   - **문제:** 실제 들어가는 콘텐츠(아이콘+텍스트 2줄)에 비해 바텀 시트가 화면의 세로를 너무 많이 차지하여 지도 뷰어의 효율을 떨어뜨림.
   - **해결:** 바텀 시트의 `padding-top`과 `padding-bottom`을 줄이고, 기본 렌더링 시 시트의 높이(Height)를 낮춰 지도가 더 많이 보이도록 비율 조정.
2. **바텀 시트 내 아이콘 크기 조정:**
   - **문제:** 중앙의 위치 핀 모양 아이콘이 텍스트에 비해 불필요하게 큼.
   - **해결:** 아이콘의 크기를 20~30%가량 축소하고, 아래 텍스트와의 간격(Margin-bottom)을 줄여 시각적 응집력을 높임.
3. **링크 버튼(FAB) 터치 영역 확보:**
   - **문제:** 우측 핑크색 링크 버튼의 시각적 크기는 적당하나, 모바일 터치 시 정확도를 높이기 위해 주변 여백이 더 필요할 수 있음.
   - **해결:** 시각적 버튼 크기는 유지하되, CSS상으로 터치 가능한 영역(Touch Target)을 48x48px 이상으로 여유 있게 설정.
