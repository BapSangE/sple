# 프로젝트 개요: 스플(Sple)

정체성: 내 취향을 스크랩(Scrap)한 나만의 핫플(Place) 지도 서비스입니다.

핵심 목표: 인스타그램에 파편화되어 있는 자료를 자동으로 정리하고, 직관적인 '나만의 지도'에 핀으로 꽂아 시각화합니다.

## 1. 디자인 연동 원칙 (Stitch MCP)

모든 프론트엔드 작업 시, 에이전트는 하드코딩을 지양하고 Stitch MCP 서버에 연결된 스플 프로젝트의 디자인 DNA를 최우선으로 읽어와 컴포넌트를 구성해야 합니다.

Primary Color (스플 코랄): #FF5A5F를 사용하며, 핫플레이스 마커(핀)와 주요 브랜드 색상에 적용합니다.

Secondary Color (스마트 퍼플): #6B4EFF를 사용하며, AI 로딩 인디케이터나 길찾기 같은 핵심 액션 버튼에 적용합니다.

Accent Color (가이드 민트): #00D09E를 사용하며, 온보딩 시선의 유도를 위한 움직이는 툴팁 등에 적용합니다.

Background (클린/오프 화이트): #FFFFFF 및 #F7F8FA를 사용하며, 주로 하단 바텀 시트 배경에 적용합니다.

Typography (딥 차콜): #1E1E1E (제목) 및 #868E96 (본문)을 사용하여 눈의 피로도를 낮춥니다.

## 2. 프론트엔드 UI/UX 레이아웃 규칙

지도 중심 설계: 앱 메인 화면의 80% 이상은 지도가 차지해야 하며, 하단 20% 영역에 바텀 시트를 제공하여 요약 리스트를 노출해야 합니다.

바텀 시트 (Bottom Sheet): 하단 패널을 스와이프 업(Swipe up)하면 상세 정보를 확인할 수 있도록 구현합니다.

콜드 스타트 (Cold Start) 방어: 초기 실행 시 지도가 비어 있을 때, 화면을 완전히 가리는 팝업은 이탈률을 높이므로 배제합니다. 대신 우측 하단(+) 버튼 위로 가이드 민트 색상의 움직이는 툴팁이 부드럽게 떠다니도록 구현합니다.

## 3. 백엔드 및 MVP 핵심 로직 규칙

데이터 수집 (Share Intent): 모바일 OS의 기본 공유 기능(Share Extension/Intent)을 통해 사용자가 인스타그램 URL을 스플 앱으로 바로 전송할 수 있어야 합니다.

개인정보 보호: 사용자의 인스타그램 계정/비밀번호 크롤링(RPA)은 절대 금지합니다.

AI 정보 추출: 수집된 URL 내의 텍스트를 LLM이 분석하여, 비정형 문맥에서 정확한 행정구역 주소와 상호명을 추출해야 합니다.

지도 매핑 (Kakao Map): 추출된 텍스트 주소를 지오코딩하여 위도/경도로 변환합니다. 국내 데이터 정확도와 카카오톡 바이럴을 고려하여 반드시 '카카오 지도 API'를 우선 연동합니다.

응답 속도 최적화: 앱 전환 시 데이터 추출부터 지도 핀 표시까지의 시간 지연을 최소화하여 즉각적인 만족감(Aha-Moment)을 제공해야 합니다.

## 4. Antigravity 에이전트 작업 파이프라인 (Step-by-Step)

디자인 주입: 프롬프트 지시에 따라 Stitch MCP에서 스플 디자인 에셋과 팔레트를 로드하여 글로벌 테마를 설정합니다.

UI 뼈대 구축: 지도 API를 띄우고 하단 바텀 시트 및 둥둥 떠다니는 툴팁 애니메이션 컴포넌트를 구현합니다.

핵심 로직 연동: Share Intent를 통해 URL을 받아오고, LLM 파이프라인으로 주소를 추출하여 지도에 마커를 찍는 백엔드 로직을 연동합니다. API 연동 보일러플레이트는 에이전트가 전담합니다.

통합 테스트: 툴팁 확인 👉 링크 공유 👉 앱 복귀 후 핀 생성 👉 바텀 시트 상세 확인으로 이어지는 전체 유저 플로우가 매끄러운지 End-to-End로 테스트합니다.
